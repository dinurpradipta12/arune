Modul 1: Beranda Aplikasi Home Dashboard & Quick Start

Halaman Beranda (Home Dashboard)

Beranda adalah pusat kendali awal untuk memulai pembuatan karya baru, membuka kembali dokumen terakhir, menelusuri katalog template editorial, serta mengakses folder proyek.

Gambar 1: Antarmuka aktual Home Dashboard dengan Quick Start cards, galeri proyek, dan tombol navigasi folder.

Fitur & Elemen Utama Beranda

1. Top Navigation Bar

Berisi logo Studio, bilah pencarian global untuk menemukan template/proyek, toggle Dark Mode, tombol Ruang Kerja Tim, tombol Project Folders, dan tombol Panduan PDF.

2. Quick Start Formats

Tiga kartu instan untuk membuat dokumen baru dalam rasio standar industri: 4:5 Portrait (1080×1350px), 9:16 Story (1080×1920px), dan 1:1 Square (1080×1080px).

3. Galeri Proyek & Folder

Menampilkan daftar proyek terakhir yang sedang Anda kerjakan lengkap dengan jumlah slide, badge status folder, dan tombol opsi "Add to Folder".

Tombol Cepat Pojok Kanan Bawah: Terdapat Floating Action Button "Panduan Pengguna (PDF)" yang selalu melayang di sisi kanan bawah untuk membuka kembali buku panduan ini tanpa mengganggu pekerjaan Anda.

Modul 2: Manajemen Berkas Project Folders & Pengelompokan Kerja

Manajemen Project Folders

Fitur Project Folders memudahkan Anda mengorganisasi puluhan hingga ratusan desain berdasarkan nama klien, kampanye bulanan, atau kategori konten.

Gambar 2: Antarmuka Project Folders dengan daftar direktori kerja, jumlah item, dan proyek yang terasosiasi.

Alur Kerja Pengelolaan Folder

1Membuat Folder Baru

Klik tombol "+ Folder Baru" di kanan atas. Masukkan nama folder (misal: "Klien Alpha - Q2 2026"), pilih warna aksen folder untuk memudahkan identifikasi visual, lalu klik Simpan.

2Memasukkan Proyek ke Folder

Dari halaman Home atau Studio Editor, klik ikon titik tiga pada kartu proyek > pilih "Pindahkan ke Folder" > centang folder tujuan > klik Konfirmasi.

3Membuka Proyek dalam Folder

Klik kartu folder untuk masuk ke direktori tersebut. Semua carousel yang tergabung akan ditampilkan dalam mode Grid atau List sesuai preferensi Anda.

4Mengedit & Menghapus Folder

Nama dan warna folder dapat diubah sewaktu-waktu. Menghapus folder tidak akan menghapus proyek di dalamnya, melainkan mengembalikannya ke folder utama (Unassigned).

Modul 3: Kolaborasi Multi-Pengguna Team Workspace & Stacked Projects

Team Workspace & Kolaborasi Tim

Team Workspace memungkinkan Anda dan rekan tim bekerja dalam satu ruang kerja tersentralisasi dengan pembaruan instan, riwayat versi snapshot, dan pembagian aset bersama.

Gambar 3: Halaman Ruang Kerja Tim aktual dengan navigasi tab Proyek Tim, Brand Kit, Anggota, serta tata letak tumpukan proyek ke bawah.

Fitur Kolaborasi Utama

Team Switcher Dropdown

Berpindah antar tim dengan satu klik pada dropdown kiri atas. Setiap tim memiliki direktori proyek, hak akses, dan Brand Kit independen.

Tata Letak Tumpukan ke Bawah

Kartu proyek tim disusun bertumpuk ke bawah (vertical stacked layout) yang rapi, memperlihatkan cover slide, pembuat, tanggal update, dan tombol aksi cepat.

Manajemen Anggota Tim

Undang anggota baru menggunakan email atau tautan unik. Tentukan peran anggota (Owner, Editor, Viewer) untuk menjaga integritas template master tim.

Keamanan Sinkronisasi Cloud: Saat menjalankan database SQL, data tim tersimpan secara aman di Supabase dengan Row-Level Security (RLS) sehingga hanya anggota terdaftar yang dapat membaca dan menyunting dokumen tim.

Modul 3: Kolaborasi Multi-Pengguna Team Brand Kit & Standarisasi Identitas

Team Brand Kit

Brand Kit memastikan seluruh anggota tim menggunakan palet warna resmi, pasangan tipografi standar, dan logo korporat yang konsisten di setiap postingan media sosial.

Gambar 4: Tab Brand Kit dalam Team Workspace memperlihatkan palet warna organisasi, font korporat, dan logo resmi.

Komponen Brand Kit Tim

1. Palet Warna Resmi (HEX)

Definisikan warna primer, sekunder, background, dan aksen tim. Palet ini akan langsung muncul di baris teratas color picker di seluruh Studio Editor anggota tim.

2. Pasangan Tipografi Tim

Tetapkan font judul resmi (Display/Heading) dan font teks paragraf (Body). Anggota tim tidak perlu menebak ukuran atau jenis huruf yang diizinkan.

3. Logo & Identitas Akun

Unggah aset logo transparan (PNG/SVG) dan tentukan default watermark atau handle Instagram (misal: @mindora.studio) yang otomatis tercantum di setiap slide.

Keuntungan Brand Kit: Memangkas waktu review desain hingga 70% karena desainer junior atau content writer otomatis bekerja dalam batasan visual identitas brand yang baku.

Modul 4: Studio Editor Anatomi Antarmuka 3-Kolom

Studio Editor: Anatomi Antarmuka

Studio Editor adalah area kerja utama tempat Anda merancang slide carousel secara mendalam dengan kanvas presisi piksel dan arsitektur kontrol 3-kolom modern.

Gambar 5: Tampilan Studio Editor aktual dengan Top Bar, Left Sidebar, Kanvas Utama, Right Inspector, dan Bottom Filmstrip.

Peta Antarmuka Studio Editor

Top Header Bar

Tombol kembali ke Beranda, judul proyek yang dapat disunting langsung, status Auto-Save Cloud, kontrol Undo/Redo, zoom persentase kanvas, tombol Preview Simulator, dan tombol Export.

Left Sidebar (Katalog)

Tiga tab utama: Slide Layers (hierarki susunan objek), Layouts & Themes (preset cover overlay, headline minimalis, palet warna), dan Font Combinations.

Right Inspector (Styling)

Panel parameter dinamis. Saat sebuah teks atau bentuk diklik di kanvas, panel ini otomatis membuka opsi tipografi presisi, spasi, bayangan, border, dan penataan posisi.

Bottom Filmstrip: Di bagian bawah kanvas terdapat bilah thumbnail urutan seluruh slide (Slide 1, Slide 2, dst.) untuk berpindah slide, menambah slide baru (+), menggandakan, atau menghapus.

Modul 4: Studio Editor Navigasi Kanvas, Zoom & Urutan Slide

Navigasi Kanvas & Manajemen Multi-Slide

Bekerja dengan carousel multi-halaman membutuhkan navigasi kanvas yang gesit, pengaturan zoom yang fleksibel, dan kemudahan mengatur urutan alur cerita.

Kontrol Navigasi Kanvas

Zooming & Fit to Screen

Gunakan tombol persentase zoom di Top Bar atau pintasan Ctrl + Scroll. Tombol "Fit" otomatis menyesuaikan kanvas ke luas jendela kerja Anda.

Panning (Geser Kanvas)

Tahan tombol Spasi lalu klik dan seret mouse untuk menggeser sudut pandang kanvas secara bebas tanpa memindahkan objek desain.

Smart Guides & Snapping

Garis pemandu merah halus otomatis muncul saat Anda menyeret elemen untuk membantu memposisikan objek tepat di tengah (center) atau sejajar dengan tepi elemen lain.

Manajemen Slide di Bottom Filmstrip

Tindakan Cara Melakukan Pintasan Keyboard
Berpindah Slide Klik thumbnail slide yang diinginkan di filmstrip bawah Panah Kiri / Panah Kanan
Tambah Slide Baru Klik tombol + Tambah Slide di ujung kanan filmstrip Ctrl + Shift + N
Duplikasi Slide Arahkan kursor ke thumbnail slide > klik ikon Copy Ctrl + D
Ubah Urutan Slide Seret (drag & drop) thumbnail slide ke posisi baru Drag manual
Hapus Slide Arahkan kursor ke thumbnail slide > klik ikon Trash Backspace / Delete
Tips Alur Carousel Editorial: Struktur 6-8 slide adalah format ideal untuk engagement Instagram. Slide 1 (Hook/Cover), Slide 2-3 (Eksplorasi Masalah), Slide 4-5 (Solusi & Studi Kasus), Slide 6 (Call-to-Action).

Modul 4: Studio Editor Sidebar Kiri: Bentuk, Ornamen & Layering

Bentuk Geometris, Ornamen & Susunan Layer

Tab Slide Layers dan elemen di sidebar kiri memberi Anda kendali penuh atas hierarki visual, bentuk ornamen editorial, garis pemisah, dan manajemen tumpukan objek.

Fitur Penataan Layer

Visibility Toggle (Mata)

Sembunyikan elemen sementara untuk melihat komposisi slide tanpa elemen tersebut tanpa perlu menghapusnya secara permanen.

Divider & Border Editorial: Garis pemisah tipis 0.5px atau 1px memberikan kesan majalah mewah kontemporer. Anda dapat menyisipkannya langsung melalui opsi Shapes di kanvas.

Modul 4: Studio Editor Sidebar Kiri: Tipografi Editorial & Font Pairs

Tipografi Editorial & Font Combinations

Tipografi adalah jiwa dari Arune Carousel Studio. Panel Font Combinations menyediakan kurasi pasangan jenis huruf terbaik dunia yang dirancang oleh desainer tipografi profesional.

Gambar 7: Katalog Font Combinations menampilkan pasangan Serif + Sans-Serif siap pakai lengkap dengan preview visual.

Preset Tipografi Populer

Kinfolk Editorial

Serif + Sans

Kombinasi Playfair Display (Judul) dan Plus Jakarta Sans (Body). Sangat cocok untuk konten arsitektur, fashion, interior, dan esai pemikiran mendalam.

Swiss Modernist

Sans + Sans

Kombinasi Inter Black dan Inter Regular. Gaya minimalis modern yang sangat efektif untuk tips bisnis, tech insights, dan carousel data/statistik.

Literary Heritage

Serif + Serif

Kombinasi Cormorant Garamond dan EB Garamond. Memberikan atmosfer sastra klasik, puisi, kutipan inspiratif, dan narasi sejarah.

Mendukung Font Komputer Lokal: Studio otomatis mendeteksi seluruh font yang terpasang di sistem operasi komputer Anda (Mac / Windows) sehingga Anda bebas menggunakan font komersial berlisensi milik agensi Anda.

Modul 4: Studio Editor Right Inspector: Penyetelan Presisi Elemen

Right Inspector: Parameter Presisi

Inspector kanan menyediakan kendali piksel mendetail untuk setiap elemen yang Anda pilih di atas kanvas, mulai dari pelacakan spasi huruf hingga efek bayangan lembut.

Gambar 8: Right Inspector saat elemen teks dipilih, menampilkan font family, bobot (weight), tracking, leading, dan drop shadow.

Daftar Kontrol Parameter Inspector

Parameter Fungsi Desain Nilai Rekomendasi Editorial
Font Family & Weight Mengubah rupa huruf dan ketebalan (Light, Regular, Medium, Bold, Black) Judul: Bold/Black, Body: Regular/Medium
Letter Spacing (Tracking) Jarak horizontal antar karakter huruf Judul Huruf Kapital: +0.05em s/d +0.15em
Line Height (Leading) Kerapatan vertikal jarak antar baris teks Judul: 1.05 - 1.15, Paragraf: 1.4 - 1.6
Color & Opacity Warna solid/HEX dan tingkat transparansi elemen Subjudul editorial: Opacity 70% - 85%
Drop Shadow & Blur Bayangan halus di belakang teks untuk kontras foto X:0, Y:4, Blur: 12px, Color: rgba(0,0,0,0.3)

Modul 5: Verifikasi Visual Instagram Feed & Swipe Simulator

Instagram Feed & Swipe Simulator

Sebelum mengunduh dan memposting konten, uji keterbacaan dan transisi slide di Simulator Instagram interaktif yang mensimulasikan layar smartphone nyata.

Gambar 9: Modal Instagram Swipe Simulator menampilkan mock smartphone beresolusi tinggi dengan interaksi swipe sentuh/mouse.

Fitur Simulasi Smartphone

1. Uji Transisi Geser (Swipe)

Seret mouse ke kiri dan kanan untuk mensimulasikan jari audiens. Perhatikan apakah teks dan elemen gambar tersambung sempurna tanpa terpotong kaku.

2. Preview Feed & UI Instagram

Lengkap dengan bilah status baterai/sinyal, foto profil pembuat, username, tombol Like, Komentar, Bagikan, Simpan, dan baris caption teks.

3. Mode Terang & Gelap Ponsel

Uji bagaimana carousel Anda tampak pada pengguna smartphone dengan tema iOS/Android Light Mode maupun Dark Mode.

Pintasan Cepat: Saat modal simulator terbuka, gunakan tombol Panah Kiri dan Panah Kanan pada keyboard Anda untuk beralih slide secara instan, dan tekan Esc untuk keluar.

Modul 6: Otomasi Konten Script Editor Markdown & Otomasi Slide

Script Editor & Konversi Markdown

Jika Anda lebih suka menulis naskah konten secara terstruktur terlebih dahulu, Script Editor memungkinkan Anda menyusun teks dalam format Markdown dan langsung mengonversinya menjadi slide visual.

Gambar 10: Modal Script Editor dengan editor naskah Markdown, parser otomatis, dan tombol sinkronisasi ke kanvas.

Aturan Penulisan Script Markdown

Sintaks Markdown Hasil Konversi Slide Kanvas Contoh Penulisan

Smart Export Multi-Format

Panduan Memilih Format Ekspor

Format Berkas Kegunaan Utama Kelebihan & Rekomendasi
PNG Ultra-HD Feed Instagram, LinkedIn, Behance Kualitas gambar tertinggi tanpa artefak kompresi (Lossless). Sangat disarankan untuk carousel editorial.
JPG Web Optimized Website, Blog, Email Newsletter Ukuran berkas kecil, loading cepat, warna cerah. Ideal jika memiliki batasan kuota upload.

Batch .ZIP Archive Arsip Lengkap Seluruh Slide Mengemas seluruh slide (Slide_01.png s/d Slide_08.png) ke dalam satu berkas zip rapi dengan penomoran urut.
